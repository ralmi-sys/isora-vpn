## Что это

Подписка на защищённый доступ в сеть. Одна ссылка — и работают телефон, ноутбук и телевизор. Без привязки карты, без автосписаний и без «умных» условий мелким шрифтом.

Внутри — пять европейских узлов и два транспорта на выбор: **XHTTP** для живучести и **TCP Vision** как резерв. Клиент сам берёт тот, что быстрее отвечает, поэтому соединение не разваливается, когда один из каналов начинает капризничать.

## Что умеет

- **Dual VLESS Reality.** XHTTP на порту 2083 — основной канал с паддингом 100–1000 байт, TCP Vision на 443 — запасной. Переключение автоматическое.
- **Hysteria2 для игр.** Отдельный UDP-профиль для Discord, Steam и всего, где важен пинг.
- **Умная маршрутизация.** Банки, Госуслуги, Ozon и Wildberries идут напрямую, без капчи и лишних кругов. Международные сервисы — через узел.
- **5 стран.** Германия, Нидерланды, Финляндия, Польша, Швеция.
- **Один ключ на всё.** До 10 устройств в зависимости от тарифа. Лимит виден в профиле, лишние можно отвязать.
- **Честный пинг.** Показываем замер, а не красивую цифру. Нет данных — стоит «—».

### Windows

Скачай установщик со [страницы релизов](https://github.com/ralmi-sys/isora-vpn/releases/latest) — файл `ISORA-VPN-Setup-<версия>.exe`.

1. Запусти установщик. Файлы пока без цифровой подписи, поэтому SmartScreen может предупредить: «Подробнее» → «Выполнить всё равно».
2. Открой ISORA и нажми «Войти через Telegram» — бот подтвердит вход, подписка и узлы подтянутся сами. Без Telegram доступен гостевой тест на 15 дней.
3. На главной выбери страну и нажми «Подключиться».

Банки, Госуслуги и маркетплейсы идут напрямую — маршрутизация уже настроена. Новые версии приложение скачивает и ставит само.

### Linux

Скачай пакет со [страницы релиза](https://github.com/ralmi-sys/isora-vpn/releases/latest) или одной командой:

```bash
curl -fL https://github.com/ralmi-sys/isora-vpn/releases/download/v1.0.3/isora-vpn_1.0.3_amd64.deb -o isora-vpn.deb
sudo apt install -y ./isora-vpn.deb
```

Вход одной кнопкой через Telegram. Подписка и узлы подтягиваются сами, обновления приходят по воздуху.

## Частые вопросы

**Правда без карты?**
Правда. 15 дней, 2 устройства, карту не спрашиваем. Понравится — продлишь, нет — просто не продлевай.

**Почему пинг иногда «—»?**
Потому что это честный замер. Если сервер не ответил за отведённое время, мы не рисуем красивую цифру.

**Сколько устройств можно?**
От 3 до 10 в зависимости от тарифа. Занятые места видны в профиле, любое можно отвязать.

**Дни сгорают при продлении?**
Нет, суммируются.
